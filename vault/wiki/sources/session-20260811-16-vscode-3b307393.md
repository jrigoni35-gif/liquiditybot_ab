## 2. `remote_control.log` forensics — the log lied, the ledger did not

**The question.** Eight remote `pause`/`snapshot` command ids appeared in
`outputs/remote_control.log` on 2026-08-01 as **RC-010 forwarded**, and were
**absent** from the exactly-once ledger `outputs/remote_consumed.json`:

```
1785619944  1785619947  1785620492  1785620496
1785622353  1785622357  1785622365  1785622368
```

**Verdict: they were never real.** They are **pytest fixture lines from
`tests/test_remote_control.py` leaking into the operator's production log** —
the pre-fix `_log()` ignored its `root` parameter and appended unconditionally
to the module-level `OUT`, while `_save_consumed(root, ...)` and `ControlChannel`
honored the tests' `tmp_path` roots. This is
[[concepts/scoped-data-unscoped-record]] — **the same class as the 2026-07-31
incident, in its own type-specimen module** — and the **LOG plane** sibling of
[[concepts/default-path-fallback-writes]].

**[K] What is on disk now:** `grep -c` over the eight ids returns **16** lines in
`outputs/remote_control.log` (two per id: `queued` + `RC-010 forwarded`), and
`outputs/remote_consumed.json` holds **5** entries with mtime **2026-07-25 19:49
local** — it has not been written since.

**[K] Re-derived timestamps** of the fixture batch (the id prefix is the epoch
second): first `1785619944` = **2026-08-01T16:32:24 local**, last `1785622368` =
**2026-08-01T17:12:48 local**.

## 5. Delegation discipline (operator directive, 2026-08-16)

**Every delegated agent that may EDIT anything runs the focused-fix 5-phase
protocol** — **SCOPE → TRACE → DIAGNOSE → FIX → VERIFY** — with the IRON LAW
*"no fixes without completing scope/trace/diagnose first"* and **escalation at 3+
cascading fixes**.

It must be embedded **BY PATH** in the agent prompt
(`C:\Users\haird\.claude\skills\focused-fix\SKILL.md`) because **subagents do not
inherit the parent's skills**:

> **An unstated protocol is an absent protocol.**

This is the same failure shape as the delegated-measurement contract — measured
cause: under-determined specs produced 5 of 9 wrong numbers in one session,
because **agents fill gaps silently rather than halting**.

**OPERATOR CARVE-OUT, same directive: OPTIMIZATIONS are exempt from the phase
gate but NOT from rigor.** Read the module first (no guessed APIs) · **measure
rather than infer** · no silent behavior changes · no cheating the code to move a
number · the DoD matrix still runs.
**Precedent cited in the directive:** parallelizing the book fetches measured
**zero** gain and was reverted — *the rate limit was the wall*.

Filed onto [[concepts/location-not-magnitude]] (§the protocol does not travel)
and [[synthesis/governance-doctrine]] **rule 20**.
