# Persistence Curve

## Definition
Each theory of offender motivation implies a different **forecast for how a manipulation class evolves**.
Choosing the wrong theory means "over-investing in detectors that never bite and under-investing in the
one lever that would."

## The four curves
| Lens | Persistence forecast |
|---|---|
| Rational choice | **Enforcement-gated, roughly constant** |
| Strain | **Loss-cycle-gated, cyclical** — worse post-crash, quieter in sustained bulls |
| Labelling | Fades only if the in-group status marker loses cultural cachet |
| Differential association | **Persists and adapts** regardless of any single venue's countermeasures |

## Why this is the useful output
The theories mostly agree on *what* to build today. They disagree on **what will still work in a year**
— which is exactly the question a detector-investment decision needs answered.

## The falsifiable test nobody is running
Strain predicts cyclicality; rational choice predicts roughly constant, enforcement-gated pressure.
The document calls this "a testable divergence" — and proposes **no experiment or ledger to adjudicate
it**. It is the clearest owed measurement in the research corpus.
