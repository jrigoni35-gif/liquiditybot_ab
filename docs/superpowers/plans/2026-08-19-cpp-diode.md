# Plan: C++ diode — the first compiled referee (offline, SAFE class)

## Context and record corrections (binding on the implementation)

Operator request 2026-08-19: build a "C++ diode" and a network design.
Three facts the build must not blur:

1. **No Rust diode exists.** `docs/research/2026-08-19_rust_evaluator_analysis.md`
   is analysis only. This C++ program is the FIRST compiled referee; the
   Rust analysis's staging (strict ingest → ledger identity → metric
   recomputation → differential report) is the design it implements.
2. **A referee is a diode: it reads ground truth and publishes findings;
   nothing feeds back into any decision path.** It is an offline analyst
   tool — never wired into the engine, never a DoD gate, never imported
   by anything in the decision pipeline.
3. **It must mirror the Python's pre-registered rules EXACTLY** (constants
   below are pre-registered; changing them after seeing data is what
   pre-registration exists to prevent). Where byte-exact replication is
   not achievable (audit hash-chain canonicalization depends on Python
   float repr), the scope EXCLUDES the check and the README says so —
   a referee that silently approximates is worse than none.

## Task 1 — `diode/lb_diode.cpp`

Single translation unit, C++17, standard library only. Compiles clean
under `g++ -std=c++17 -O2 -Wall -Wextra -Werror` and (by construction —
no POSIX APIs, no `#pragma`, files opened in binary mode and `\r`
stripped) under MSVC. CLI: `lb_diode <outputs_dir>`; writes ONE JSON
object to stdout, exit 0 on success, 2 on unreadable outputs dir. Never
crashes on malformed input — every malformed row is COUNTED, never
coerced (the strict-ingest law).

### Modules (all in one file, clearly sectioned)

**S0. Strict CSV reader.** Header-indexed; a row whose field count
differs from the header is dropped AND counted (`dropped_short` /
`dropped_long`). RFC-4180 quoted fields with embedded commas/quotes
supported (signal_history text columns may quote). CRLF tolerated.

**S1. Minimal-but-correct JSON parser** (recursive descent: objects,
arrays, strings with `\uXXXX` and standard escapes, numbers, true/false/
null). Used for audit.jsonl records; a line that fails to parse is
counted (`bad_lines`), not skipped silently.

**S2. Ledger scan — `equity.csv`.** Columns ts,equity(,...): rows,
dropped counts, equity start/end/min/max over VALID rows, in `double`
(comparison tolerance handled by the harness; the exact-decimal
accounting identity needs fills×marks joins that are out of v1 scope).

**S3. Era-4 trip reconstruction — `fills.csv`** (the heart; mirrors
`scripts/cohort_eval.era4_trips` rule-for-rule):
- group rows by `position_id` (skip rows with empty pid), sort each
  group by ts ascending (stable);
- per leg: `fill_size` (>0), `fill_price` (>0), `fees_delta_usd` parse
  or the whole trip is invalid (`ok=false`);
- cash += size*price on side=="sell", −= on buy; fees += fees_delta;
- purpose in {"entry","hedge"} = opening leg (first one sets `opened_by`
  and t_open; accumulate entry size esz and entry notional enot);
  purpose=="exit" accumulates exit size xsz and sets tclose (last exit);
- trip is a closed round trip iff ok && esz>0 && xsz>0 && enot>0 &&
  tclose set && |xsz−esz|/esz ≤ 0.02;
- duplicate-signature drop: signature = ordered list of (purpose, side,
  round(size,6), round(price,4)); a repeated signature is dropped.
  round() must match Python banker-independent formatting: use
  `std::llround(v * 1e6) / 1e6` and `1e4` respectively (values in play
  are far from the tie cases; the harness pins agreement);
- verdict population: `opened_by=="entry"` only, and
  `tclose >= max(B4_TS, CAPITAL_EPOCH_TS)`;
- outputs per trip gross_pct = 100*cash/enot, net_pct =
  100*(cash−fees)/enot.

Pre-registered constants, verbatim:
```
B4_TS            = 1786359815.0   // 2026-08-10T11:03:35Z (aeeaae36)
CAPITAL_EPOCH_TS = 1786403127.0   // 2026-08-10T23:05:27Z
ERA4_MIN_N       = 50
```

Report: accrual_n, target, gross/net mean and median, n_pos_gross,
plus min/max tclose (so a human can see the window).

**S4. Corpus scan — `signal_history.csv`.** rows by `source` value,
label counts (label=="1" wins over valid labeled rows), base rate, and
Wilson(k, n, z=1.96) mirroring cohort_eval.wilson exactly:
p, lo = max(0,c−h), hi = min(1,c+h) with c=(p+z²/2n)/(1+z²/n),
h = z·sqrt(p(1−p)/n + z²/4n²)/(1+z²/n).

**S5. Audit counts — `audit.jsonl`.** records, bad_lines, count by
`code` (top 12, count-desc then code-asc for determinism), min/max ts.
NO chain verification in v1 (see record correction #3); the JSON output
carries `"chain": "out-of-scope-v1"` so nobody mistakes absence for a
pass.

**S6. Report.** One JSON object:
```json
{"diode": "cpp", "version": 1, "outputs_dir": "...",
 "ingest": {"equity": {...}, "fills": {...}, "signal": {...}, "audit": {...}},
 "equity": {...}, "era4": {...}, "labels": {...},
 "audit_codes": {...}, "chain": "out-of-scope-v1"}
```
Numbers printed with `%.10g` (printf) so the harness parses them
losslessly at its 1e-9 tolerance. ASCII only.

> **Correction (2026-08-19):** shipped code uses `%.17g`, not `%.10g` —
> review fuzzing tripped `%.10g` at gross ~100% (it quantizes ~5e-10
> RELATIVE, missing the harness's 1e-9 ABSOLUTE tolerance once
> |value| >= 10). See the S6 comment in `diode/lb_diode.cpp`. Do not
> reconstruct a second tool from this line as written.

## Task 2 — `tests/test_cpp_diode.py` (same commit)

Differential harness. `pytest.mark.skipif(shutil.which("g++") is None
and shutil.which("clang++") is None, ...)` — the PC's Windows battery
has no compiler and must stay green; the SKIP prints that reason.

- Compile `diode/lb_diode.cpp` once per session to tmp
  (`-std=c++17 -O2 -Wall -Wextra -Werror`); a compile failure is a TEST
  FAILURE (the file must always build).
- Fixture A (synthetic): build an outputs dir with (a) a valid
  entry-opened era-4 round trip in the real fills schema, (b) a
  hedge-opened trip (must be EXCLUDED), (c) a pre-epoch trip (excluded),
  (d) a duplicate-signature trip (dropped), (e) a torn short fills row
  (counted dropped, not coerced), (f) equity.csv with one short row,
  (g) a small signal_history.csv via ml.history.HistoryStore's header
  with known live/candidate/label mix, (h) audit.jsonl with known code
  counts plus one garbage line.
- Run the binary; parse its JSON; assert against PYTHON ground truth
  computed in the test by calling `scripts.cohort_eval.era4_trips` and
  `scripts.cohort_eval.wilson` on the same fixture (the differential
  loop is Python-vs-C++ on identical inputs, not hand-written expected
  values): accrual_n, each trip's gross/net to 1e-9, Wilson triple to
  1e-9, per-source row counts, dropped counts, audit code counts.
- Fixture B (degradation): empty outputs dir → binary exits 0, all
  sections report zero rows, valid JSON.
- All writes under tmp_path (conftest outputs-guard).
